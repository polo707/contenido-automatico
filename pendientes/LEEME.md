# Subí tus imágenes acá 📥

Se publican en orden alfabético (de la A a la Z / del 1 al 9), una por cada horario.
Formatos: JPG, PNG, WEBP, HEIC (iPhone). Cualquier tamaño: se adaptan solas.

Para darle un texto propio a una foto, subí un .txt con el mismo nombre
(ej: `003.jpg` + `003.txt`). Si no, se usa el siguiente texto de `textos.txt`.
